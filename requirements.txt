# Corner Pocket: the third-party packages the code imports directly.
# Needs Python 3.12 or newer (numpy 2.5). The test suites pass with these
# versions on Python 3.14, Linux.
#
#   python -m venv .venv
#   .venv/bin/pip install -r requirements.txt
#   .venv/bin/python scripts/fetch_weights.py
#
# torch and torchvision: plain PyPI gives the default Linux build (CUDA). For
# a CPU-only or an AMD ROCm build, install them from the PyTorch index first,
# then this file; the pins below match "2.9.1+cpu" and "2.9.1+rocm6.4" too,
# so the build you installed stays.
#   CPU only:  pip install torch==2.9.1 torchvision==0.24.1 --index-url https://download.pytorch.org/whl/cpu
#   AMD ROCm:  pip install torch==2.9.1 torchvision==0.24.1 --index-url https://download.pytorch.org/whl/rocm6.4
# Everything runs on the CPU; a GPU, when torch sees one, only makes some
# detectors faster. (Development uses the ROCm 6.4 build.)
